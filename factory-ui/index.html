Verdict

Run another round

A round is one pass of the six agents over one change. Repeating a round needs a new change, not a re-run: the chain diffs your branch against its base, so running twice on the same branch just reprocesses the same diff. round.sh refuses that rather than showing you a confusing no-op.

  1. Start a branch. This stops so you can edit. cd factory-ui && ./round.sh --fresh my-change
  2. Make one small change in wordgolf-lab/word-golf and commit it. Do not add a flag: that is the pipeline's job, and a pre-flagged change defeats the exercise.
  3. Run the chain. Switch the source above to Live run to watch. ./round.sh

Usually 10 to 15 minutes. It can exceed 45 if a model call times out and retries, and nothing on this screen will say so, so do not kill a run that looks stuck on one step.

Show the approval gate instead, which is the point worth making: the gate is a LaunchDarkly flag, not a code setting.

  1. Hold this round at the gate../round.sh --gate --fresh gated-change
  2. Back to running straight through../round.sh --no-gate

Use --gate (serves always), not the risk-threshold mode: the threshold is 0.6 and these changes score about 0.25, so they would sail through and the gate would look broken.
